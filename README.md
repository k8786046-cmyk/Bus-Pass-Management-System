# 🚌 Bus Pass Management System

A web-based Bus Pass Management System developed using PHP and MySQL.

## 📌 Project Description
This project helps students register, apply for bus passes, and manage their applications online. The administrator can manage bus pass applications through the system.

## 🚀 Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## ✨ Features
- Student Registration
- Student Login
- Admin Login
- Bus Pass Application
- View Bus Pass Details
- Manage Applications
- Database Integration

## ⚙️ Installation Steps
1. Install XAMPP.
2. Copy the project folder into the htdocs directory.
3. Start Apache and MySQL.
4. Import the database using phpMyAdmin.
5. Open the project in your browser.
